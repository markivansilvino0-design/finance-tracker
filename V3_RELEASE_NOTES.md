# Finance Tracker PWA V3

## Upgrades
- Automatic Google Sheets sync after local changes when a Web App URL is connected.
- Manual **Sync Now** button remains available.
- Restore from Sheets now asks for confirmation before replacing device data.
- Installments now calculate financed amount, monthly payment, total payable, remaining balance, and progress.
- Optional monthly payment override for plans with fees/interest.
- Optional automatic posting of the financed purchase amount to the selected credit-card balance.
- First due date is stored separately from purchase date.
- Installment payment progress automatically advances the next due date.
- PWA service-worker cache bumped to V3.
- Added 192px and 512px PWA icons.
